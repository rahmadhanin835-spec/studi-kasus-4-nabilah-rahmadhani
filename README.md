1. Dictionary buku :
Digunakan untuk menyimpan data buku dalam bentuk pasangan key dan value, yaitu judul, penulis, dan tahun terbit.

3. while True :
Digunakan untuk membuat program terus berjalan dan menampilkan menu berulang kali sampai pengguna memilih menu keluar.

5. print() :
Digunakan untuk menampilkan menu dan informasi kepada pengguna.

7. input() :
Digunakan untuk menerima masukan dari pengguna, seperti pilihan menu, nama penerbit, dan nama penulis.

9. if, elif, dan else :
Digunakan untuk menentukan tindakan yang dilakukan berdasarkan pilihan menu pengguna.

11. buku["penerbit"] = penerbit :
Digunakan untuk menambahkan data penerbit baru ke dalam dictionary.

13. buku["penulis"] = penulis :
Digunakan untuk mengubah data penulis yang sudah ada dengan data baru.

15. del buku["penerbit"] :
Digunakan untuk menghapus data penerbit dari dictionary.

17. break :
Digunakan untuk menghentikan perulangan while True ketika pengguna memilih menu keluar.

19. else :
Menampilkan pesan bahwa pilihan menu tidak valid jika pengguna memasukkan pilihan selain 1–5.
